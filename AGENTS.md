# Working on Fieldnotes

- Read `.agents/skills/shadcn-svelte/SKILL.md` and `.agents/skills/ui-ux-pro-max/SKILL.md` before UI changes. Use `design-system/fieldnotes/pages/study.md` for this workspace.
- Use Bun and the installed native shadcn-svelte components. Use Svelte 5 runes and the `#lib` aliases from `components.json`.
- Worked solutions live in `content/exam*.py`. Exact original English questions live in `content/original_questions.py`; faithful Chinese translations live in `content/question_translations.py`. Rebuild with `python3 scripts/build_content.py`. Never paraphrase the original questions, silently correct their givens, replace worked parts with placeholders, or remove a source-correction note.
- Before each problem’s derivation, include the authored bilingual guide from `content/problem_guides.py`: concepts, actual givens, goals and starting approach, followed by the existing verified lecture-page links. Keep this separate from the verbatim question and do not treat computed answers as givens.
- Keep both languages, upright units and explicit coordinate/sign conventions. Cite the original crib equation when available; derived formulas must be explained.
- Every worked subpart starts with a displayed governing equation, not only a formula link, and then shows the actual substitutions and intermediate algebra or calculus. Keep integral elements, dot products, limits, antiderivatives, boundary constants, units and vector directions explicit where applicable. Do not compress detailed solutions back into two-step summaries. Check both equations and drawings against the official PDFs; inspect page images when answers are handwritten and absent from extracted text.
- Gaussian-surface solution diagrams use R for the fixed surface radius and separate dummy integration coordinates. Draw a, b and R from the same center to their own boundaries, show the outward normal and the enclosed charge, and distinguish volume density from surface density. Preserve source corrections explicitly. For the F26 matching-interface question, select a, b and c: local interface reflection coexists with zero net feedline reflection.
- Source page numbers are 1-based PDF pages. Preserve the PDF copies and SHA-256 provenance. All citation rectangles must fit inside the page and match the cited expression.
- Question figures stay static SVG with the original-image switch. The spherical diagram uses a shared orthographic projection: far equator behind the inner ball, near equator in front, radii ending on their spherical silhouettes. Interactive 3D belongs only in the revealed solution as an optional tool; do not make it the question’s default figure.
- Generate scientific figures with `scripts/generate_figures.py` using Matplotlib and SVG text. `scripts/question_figures.py` recreates source diagrams using the exact regions in `content/source_figures.py`. Preserve each original perspective, topology, axis, label and given/unknown quantity: a 3D source must retain its 3D view. Keep solution plots and annotations in revealed solutions, not in question figures. Keep both color themes and the original figure switch.
- Figure labels use large, bold text including math symbols, clear of arrows and strokes. Keep the source-exam action in a reserved lower-left figure area in both views; switching figures must preserve the drawing height. Omit boilerplate recreation captions. Results belong in the final derivation step and use only KaTeX boxed emphasis; do not add an answer card, outer border or final-answer heading. Navigate questions in the sidebar; do not restore the bottom pager.
- Titles, statements and subparts follow the global language: Chinese directly translates the original exam text; English shows that original text. Do not add a separate translation switch, supplemental translation panel, or duplicate bilingual question blocks. Practice is done on paper; do not restore the per-part attempt textarea. Use one global solution toggle: if any part is open, collapse all; if none is open, reveal all. Its label and state must follow individual accordion changes as well.
- The source viewer uses consistent native 36 px controls. When width and height allow, show all PDF pages as a vertical, independently scrolling thumbnail list. Clicking a thumbnail changes pages; highlight and automatically reveal the selected page when the toolbar changes it. Preserve the citation marker on its original thumbnail and the visible-region marker on the current page; clicking or using arrow keys on the current thumbnail navigates within the main page. On small screens, preserve the reading area and hide the overview.
- Keep independent navigation and reference sidebar toggles in the top bar, using native shadcn buttons and tooltips. Collapsed panels release reading width and are inert; preserve their internal tab/accordion state and save desktop preferences. On compact screens, the same controls open the existing navigation/reference Sheets without changing desktop preferences. Keep focus outside collapsed panels and respect reduced motion.
- Keep runtime assets local and localStorage versioned. Do not add a notes tab, note-taking inputs, or note export controls; practice is done on paper. Preserve existing stored records during feature removals. Do not publish course PDFs or add remote services as part of routine edits.
- Run `bun run check`, `bun test`, and `bun run build` for substantive changes. Exercise the affected UI in the browser at desktop and phone widths.
- After scientific figure changes, run `python3 scripts/check_figures.py` in the Matplotlib environment. It checks both themes, label collisions and spherical radius/normal geometry without rewriting static assets.
